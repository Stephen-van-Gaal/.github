# Security policy

This policy applies when a repository in the `Stephen-van-Gaal` organization does not publish a local security policy.

## Supported versions

Only the current default branch and the latest published release receive security fixes unless a repository states otherwise.

## Report a vulnerability privately

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or commit.

For a public repository with private vulnerability reporting enabled, open its **Security** tab, choose **Advisories**, and select **Report a vulnerability**.
If that option is unavailable, contact `@stvangaal` through an existing private collaboration channel and include the repository name.
For a private repository, use its private issue tracker or the team's established private channel.

Include the affected repository and version, the impact, reproduction steps, and any suggested mitigation.
Do not include live credentials, private keys, personal information, or production data.

The maintainer will confirm receipt, assess the report, and coordinate disclosure after a fix or mitigation is available.
