# Organization GitHub defaults

This public repository holds community-health files that GitHub applies to repositories in the `Stephen-van-Gaal` organization when they do not provide a local version.
It gives repository owners, contributors, and coding agents one default for proposing changes and reporting security concerns.

The inherited files are:

- `pull_request_template.md` for change summaries and verification;
- `CONTRIBUTING.md` for the shared contribution workflow;
- `SECURITY.md` for private vulnerability reporting;
- `profile/README.md` for the public organization profile.

Repository-local files override these defaults when a project needs stricter or more specific guidance.
This repository deliberately provides no generic issue templates because several projects use issue forms tied to their own workflow.
